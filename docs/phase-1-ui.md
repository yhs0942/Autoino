# 1단계: 기본 화면 구현

> 이 문서는 1단계 당시의 기록입니다. 이후 추가된 기능은 [2단계 문서](phase-2-wiring.md)를 참고하세요.

## 구현 범위

| 기능 | 상태 |
| --- | --- |
| 3단 레이아웃 (라이브러리 · 작업 공간 · 속성) + 상단 헤더 + 하단 상태 표시줄 | 구현 |
| 메인 보드 선택 (Uno R3, Mega 2560, Nano) 및 핀 수 표시 | 구현 |
| 부품 라이브러리 검색 · 카테고리 필터 | 구현 |
| 부품 추가 (버튼 / 드래그 앤 드롭), 캔버스 내 이동 | 구현 |
| 부품 개별 선택 · 삭제 (버튼, Delete 키) | 구현 |
| 보드 / 부품 속성 패널 | 구현 |
| 초기화 (확인 대화상자 포함) | 구현 |
| 연결 방식 패널 (UART · I²C · SPI) | 안내 UI 만 구현 (실제 연결 없음) |
| 내보내기 | "준비 중" 안내만 표시 |
| 핀 간 배선, 자동 핀 배정, 저항 선정, 전기적 검증 | 미구현 |
| 프로젝트 저장 · 불러오기 | 미구현 |

## 데이터 구조

- `Board` (`frontend/src/data/boards.ts`): 보드 사양과 핀 목록. 각 핀은 `capabilities`
  (digital, analog, pwm, interrupt, i2c-*, spi-*, uart-*) 를 가지며 자동 핀 배정의 입력이 된다.
- `Module` (`frontend/src/data/modules.ts`): 부품 종류의 공통 정의. 각 핀은 `requires`
  (필요한 보드 핀 기능)를 가진다.
- `PlacedModule` (`frontend/src/state/circuitState.ts`): 작업 공간에 배치된 인스턴스.
  고유 `instanceId`, 표시 이름, 좌표, `pinAssignments`(현재는 모두 `null`)를 가진다.
- 전기적 사양은 `confidence` 로 신뢰도를 구분한다.
  `official`(공식 사양) / `typical`(대표값, 제품 확인 필요) / `varies`(제품별 상이).

상태 변경은 `circuitReducer` 순수 함수로만 이루어지므로 UI 없이 테스트할 수 있고,
이후 백엔드 동기화나 저장 기능을 같은 액션 단위로 연결할 수 있다.

## 다음 단계 후보

1. 핀 단위 배선 편집기 (모듈 핀 ↔ 보드 핀 드래그 연결, 연결 데이터 모델)
2. 자동 핀 배정 엔진 (`requires` ↔ `capabilities` 매칭, 충돌 시 재배치)
3. LED 직렬 저항 등 저항값 자동 계산
4. 프로젝트 저장 · 불러오기 (JSON), 부품·보드 데이터를 `data/*.json` 으로 분리
5. 전기적 검증 (전류 한도, 전압 레벨, I²C 주소 중복 등)
