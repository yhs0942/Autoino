### 새 핀 역할

| 역할 | 뜻 | 보드 핀 연결 |
| --- | --- | --- |
| `source` | 전원을 내보내는 핀 (외부 전원 +, 레귤레이터 출력) | VIN 또는 같은 전압의 전원 핀만 |
| `load` | 모터 단자 | 금지 (드라이버 출력에 연결) |
| `drive` | 드라이버 출력 | 금지 (모터 단자에 연결) |

전원 핀에는 `minVoltage`, `maxVoltage`, `typicalMa`, `peakMa` 가 있고, 외부 전원이 필요한 핀은 `external` 이 `required`(보드 전원에 자동 연결하지 않음) 또는 `recommended` 입니다.
드라이버는 `driver.channels` 로 채널을 정의합니다. 쓰지 않는 채널의 제어 핀은 연결하지 않아도 되며 미연결 경고도 내지 않습니다.

## 자동 핀 배정

1. 모터 단자를 같은 보드의 드라이버 빈 채널 출력에 잇습니다. 채널의 `accepts` 가 모터 종류와 맞아야 합니다.
2. `external` 전원 핀은 허용 전압 안의 외부 전원에 잇습니다. 없으면 `required` 는 실패로 알리고 `recommended` 는 보드 전원을 씁니다.
3. 외부 전원을 쓰는 부품의 첫 GND 는 전원 − 로, 전원 − 는 보드 GND 로 잇습니다. 모터 전류가 보드를 지나지 않게 하기 위해서입니다.
4. 드라이버는 쓰는 채널의 제어 핀만 GPIO 에 잇습니다.

## 배선도 위 브레드보드

별도 보기를 없애고 브레드보드를 배선도의 객체로 옮겼습니다. 끌어서 옮길 수 있고 클릭하면 레일과 구멍별 배선표를 보여 줍니다.

- 툴바의 **새 전선** 에서 `보드 직결` / `브레드보드 경유` 를 고른 뒤 전선을 끕니다. 이미 만든 전선은 선택해서 바꿀 수 있습니다.
- 전선에는 `via: "breadboard"` 만 저장합니다. 구멍 위치는 `routeBreadboard()` 가 연결에서 계산하므로 전선을 바꾸면 배치도 따라 바뀝니다.
- GND·전원 넷은 레일, 나머지 넷은 빈 열의 스트립을 씁니다. 스트립이 차면 점퍼로 다음 스트립을 잇습니다. LED 직렬 저항은 가운데 홈을 건너 꽂습니다.
- `verifyRouting()` 이 구멍·레일·점퍼를 따라 연결을 다시 만들어 배선도와 일치하는지, 다른 넷이 단락되지 않았는지 검사합니다.
- 브레드보드 위에 전선을 놓으면 그 핀에 맞는 보드 핀을 자동으로 골라 브레드보드 경유로 연결합니다.
- 자동 배정은 1 A 이상 흐르는 전선을 브레드보드로 보내지 않습니다. 직접 보내면 `breadboard-current` 경고를 냅니다.

프로젝트 파일 형식은 버전 2 그대로이며 선택 항목 `connections[].via`, `breadboard` 가 추가되었습니다. 예전 파일은 모든 전선이 직결로 열립니다.

## 전원 탭

`analyzePower()` (TS) / `analyze_power()` (Python) 가 계산합니다.

- **필요한 외부 전원**: 드라이버(전압 강하를 더한 모터 전압 범위), 드라이버 없는 모터, `external` 부품을 전압 범위가 겹치는 것끼리 묶습니다.
  - 최소 전류: 평상시 전류 합 × 1.25, 권장 전류: 기동·스톨 전류 합 (100 mA 단위 올림)
  - 예시는 `data/power-supplies.json` 에서 전압 범위와 최소 전류를 만족하는 것을 고릅니다. 권장 전류를 만족하는 것, 목표 전압에 가까운 것부터 최대 4개를 보여 주고 배터리는 예상 사용 시간을 계산합니다.
  - **적용** 은 외부 전원 부품을 놓고 전원·GND 를 연결합니다.
- **현재 전원 상태**: 전원마다 평상시·최대 전류와 용량을 비교합니다. 레귤레이터 입력에는 출력 부하를 그대로 더합니다 (실제 벅 컨버터의 입력 전류보다 크게 잡는 보수적 계산).

### 전원 검사 규칙

| 코드 | 수준 | 내용 |
| --- | --- | --- |
| `supply-overvoltage` | 오류 | 전원 전압이 부품 허용 전압을 넘음 |
| `supply-undervoltage` | 경고 | 외부 전원이 최소 동작 전압보다 낮음 |
| `supply-overload` / `supply-peak` | 오류 / 경고 | 평상시 / 기동·스톨 전류가 전원 용량을 넘음 |
| `supply-parallel` | 경고 | 전원 두 개의 + 를 바로 이음 |
| `motor-overvoltage` / `motor-undervoltage` | 오류 / 경고 | 드라이버 전압 강하 뒤 모터 전압이 범위를 벗어남 |
| `driver-overcurrent` / `driver-peak` | 오류 / 경고 | 모터 전류가 채널 정격을 넘음 |
| `regulator-headroom` | 경고 | 레귤레이터 입력이 출력보다 충분히 높지 않음 |
| `module-ground-not-common` | 오류 | 신호는 보드에 연결됐는데 GND 가 이어지지 않음 |
| `vin-undervoltage` / `source-on-supply` | 경고 | VIN 전압이 낮음 / 5V 핀에 전원을 직접 넣음 |
| `module-input-overvoltage` | 경고 | 3.3 V 입력에 5 V 보드 신호가 들어감 |
| `breadboard-current` | 경고 | 브레드보드로 1 A 이상 흐름 |

## 시뮬레이션

외부 전원과 레귤레이터 출력은 전압원으로, 드라이버는 전원 핀의 전류 부하(자체 전류 + 모터 전류)로 계산합니다. 모터별로 모터 전압과 상태를 보여 주고, 모터를 스톨 상태로 바꿔 전원이 버티는지 볼 수 있습니다.
시간에 따른 동작, PWM, 배터리 전압 강하는 다루지 않습니다.

## Streamlit

`streamlit_app.py` 가 `streamlit.starlette.App` 으로 Autoino API 와 빌드된 프런트엔드를 `/autoino` 경로에 얹고, `streamlit_page.py` 가 그 화면을 창 가득 띄웁니다.
포트는 Streamlit 포트 하나만 쓰므로 같은 네트워크의 다른 PC 에서 접속해도 API 가 함께 동작합니다.
프런트엔드는 상대 경로(`base: './'`, API `api/...`)로 빌드되어 어느 하위 경로에 얹어도 열립니다.
